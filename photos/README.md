# /photos

Drop your images here.

- Scrapbook photos: `photo1.jpg`, `photo2.jpg`, `photo3.jpg`, ... matching the
  `src` values in the `PHOTOS` array at the top of `js/script.js`.
- Site chrome images also live here: `wallpaper.png` (desktop/book
  background), `lock-screen.png` (password screen), `digi-scrap-icon.png`
  (desktop icon), `closed-diary.png` (the "Digi Scrap.exe" window).

Any of these files can be `.jpg`, `.jpeg`, `.png`, or `.webp` — just update the
extension in the matching `src` entry in `js/script.js` to match what you upload.

Until a file exists, that spot shows a cute "add your photo here" placeholder
automatically — nothing breaks if you add photos gradually.

See the main `README.md` in the project root for the full walkthrough.
